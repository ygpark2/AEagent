- (capability) CAP-1: Human Approval Suspension and Resumption. Intent: Execution transitions to resumable :suspended state on approval request and continues automatically once approved. Success: Stalled run resumes from blocked node and completes without restart.
- (capability) CAP-2: Isolated Node-Level Fan-In Context Merging. Intent: Engine merges concurrent node outputs without key collisions or artifact loss. Success: Parallel branch outputs isolated under node_outputs[node_id] with artifacts concatenated.
- (capability) CAP-3: Deep-Atomized Schema-Safe Context Deserialization. Intent: Persist execution context to JSON and restore control keys as atoms. Success: Resumed execution context pattern matches successfully against atom keys.
- (capability) CAP-4: External MCP Tool Health Monitoring and Circuit Breaking. Intent: Track tool availability and mark repeatedly failing tools unavailable. Success: Consecutive errors trip circuit breaker to unavailable state before next LLM call.
- (capability) CAP-5: Capability Scopes and Path/Domain Boundaries for Tools. Intent: Enforce capability scopes (file_read, file_write, shell_exec, web_fetch) and path/domain boundaries. Success: Unauthorized file write or out-of-domain network call halted by PolicyGate.
- (capability) CAP-6: Watchdog for Stuck Execution Detection and Timeout Management. Intent: Detect stalled/orphaned executions and time them out. Success: Stalled tasks automatically transition to timed_out state and unlock resources.
- (capability) CAP-7: Dashboard Historical Execution Exploration and Replay. Intent: List, search, filter, and replay past execution timelines and events. Success: Operators can query historical runs on /agent dashboard and inspect full timeline.
- (constraint) Strict compliance with ARCHITECTURE-SPINE.md (AD-1 to AD-5); local development must remain functional on SQLite3 without mandatory docker daemon
- (decision) Non-goals: Multi-node distributed clustering; real-time typewriter token streaming over WebSockets.
